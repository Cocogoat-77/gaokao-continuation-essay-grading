# 问题标签库 / 错误类型库 / 衔接检查用语

## 一、问题标签库（`tags`，每篇取 2–3 个）

标签必须从下列固定集合中选取，格式为不带 `#` 的短语（渲染时自动补 `#`）。

**情节类**
- 情节不够合理
- 情节偏离原文
- 与前文的衔接较差
- 与所给提示句的衔接较差
- 情节不完整
- 情感转折突兀
- 结尾升华生硬

**语言类**
- 基础语法错误较多
- 时态不一致
- 词性误用
- 固定搭配错误
- 句式单一
- 中式英语表达
- 拼写错误偏多

**书写类**
- 卷面需改进
- 书写辨识度低

## 二、错误类型库（`errors[].type`）

括号内为标题中显示的完整形式。选取优先级：语法硬伤 → 用词搭配 → 拼写。

| 类型 | 说明要点 |
|---|---|
| 被动语态错误 | 不及物动词无被动语态 |
| 时态误用 | 与全文叙述时态（一般过去时）不一致 |
| 主谓一致错误 | 单复数与谓语不匹配 |
| 词性误用 | 名词/动词/形容词混用，如 weight 当动词 |
| 非谓语动词错误 | 分词、不定式形式或逻辑主语错误 |
| 句子成分残缺 | 逗号连接两个独立句、缺谓语或缺主语 |
| 从句错误 | 关系词、引导词误用 |
| 介词误用 | 搭配不当或缺失 |
| 冠词误用 | 定冠词/不定冠词/零冠词 |
| 名词单复数错误 | 可数名词复数形式、不可数名词误用复数 |
| 固定搭配错误 | 动词短语、介词短语搭配有误 |
| 代词指代错误 | 人称、数、格不一致 |
| 拼写错误 | 逐词指出正确拼写 |
| 语序错误 | 疑问句、倒装或状语位置有误 |
| 用词不当 | 词义不符语境，需替换更准确的词 |

每条错误的 `note` 格式：`{词性或语法点}是{说明}，此处{应如何}，{补充原因}。` 一句话讲清，20–45 字。

## 三、衔接&过渡检查用语（`cohesion`）

**固定检查项（顺序不可变）**

第一段分析：
1. `你的第一句与提示句1的衔接`
2. `你段内句子间的过渡`

第二段分析：
3. `你的结尾句与提示句2的衔接`
4. `你的第一句与提示句2的衔接`
5. `你段内句子间的过渡`

**判定用语（只能用这些）**
- 衔接：`衔接不当` / `衔接生硬` / `衔接自然`
- 过渡：`存在多处逻辑跳跃` / `存在不符合场景的逻辑跳跃` / `过渡基本自然`

**`detail` 句式**：`{判定}。{指出具体问题}。` 其中必须点出学生原文的具体句子或情节，不得泛泛而谈。
**`advice` 句式**：`{动作指令}，{替换为/修改为/补充} {完整英文句子}。` 优化建议必须给出可直接抄用的英文句子，不能只说"建议优化"。

**每条检查项判定为"衔接自然／过渡基本自然"时**，`advice` 写 `保持现状，此处处理得当。`

## 四、高频错误清单（用于快速定位，非穷尽）

- 逗号连接两个独立句（run-on sentence）
- 不及物动词被动化
- 名词当动词/动词当名词
- `human` 未用复数 `humans`
- `should + 名词`（应为 `should live in harmony` 这类动词结构）
- 过去时段落中出现一般现在时
- `advice` 用复数 `advices`
