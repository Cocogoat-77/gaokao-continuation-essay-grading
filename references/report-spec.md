# 报告规格书（版式 + 数据契约）

本文件是复刻目标报告的唯一权威规格。所有版式数值来自对一份**批改报告样本**的逐元素测量（A4 全页），不是估计值。规格与具体题目无关，任何一次批改都按本文件渲染。

## 一、版式基准

| 项目 | 值 |
|---|---|
| 纸张 | A4，595 × 842 pt |
| 页边距 | 左右各 20 pt；上 40 pt、下 40 pt（页眉页脚占用此区） |
| 正文字体 | 中文 幼圆 YouYuan；英文 Times New Roman |
| 正文 | 9 pt，行距 1.3（实测行距 11.7 pt），两端对齐 |
| 大标题 | 20 pt，居中，格式 `{M}月{D}日{题型}-{姓名}`（如 `9月18日读后续写练习-张三`，`{题型}` 取自 `assignment.json`） |
| 页眉（每页） | 右对齐：`班级：{}班  \|  学号：{}` 8 pt + `{姓名}` 15 pt |
| 页脚（每页） | 居中 `第{n}页/共{N}页` 10 pt `#808080`；右侧 `{YYYY/MM/DD} 星期{X}` 10 pt 黑 |
| 段落间距 | 板块之间约 20 pt；板块标题与首个内容之间约 12 pt |

## 二、颜色表

| 用途 | 色值 |
|---|---|
| 正文、标题、`【】`标签 | `#000000` |
| 板块标题、板块虚线、`【高级词汇】`等强调标签、正文中的替换建议 | `#0F86FF` |
| 修订：学生的错误原文（`<del>`） | `#FF0000` 文字 + 0.6 pt 红色删除线，**无底纹** |
| 修订：订正文本（`<ins>`） | `#CACACA` 灰底 + `#FF0000` 红字，无删除线 |
| 问题标签底、段落分析标签底、卷面点评底板 | `#DBEDFF` |
| 问题标签底板、卷面点评实心药丸 | `#0F86FF`（白字） |
| 出彩表达绿条 | `#0DBC51` |
| 学生佳句行底 | `#F8F9FA`，行间虚线 `#DCDCDC` |
| 场景词汇单元格描边 | `#EB5415` |
| 页码 | `#808080` |
| 小标题卡图标框 | 底 `#FDF0DC`、边 `#E8B463`、图标 `#B07414` |

## 三、板块顺序与构成（11 个板块，缺一不可）

1. **大标题**
2. **评语**（蓝色板块标题带虚线）——四行固定小标题：`【得分】`、`【完成度】`、`【情节内容】`、`【词汇句式和语法】`
3. **本次作文我的问题**——2 个左右问题标签，浅蓝药丸 + 右下偏移 3 pt 的实蓝底板，格式 `#标签名`
4. **卷面点评**——浅蓝长药丸，内含实蓝药丸（白字 `卷面点评`）与等级文字（优秀／中等／差）；下方一段卷面描述
5. **逐句批改**——`Paragraph 1:` / `Paragraph 2:` 两段学生原文全文；错误处用**红字 + 红色删除线**，紧跟**订正文本（浅灰色底 `#CACACA` + 红字）**

> **转写规则（老师明确要求）**：学生**自己划掉或涂改的词一律不进入转写文本**。转写呈现的是学生最终想保留的文本——划掉的词不出现、不计词数、不算语法错误。这里的 `<del>` 只用于指出真实错误并给出订正，不得用来还原学生的自改痕迹。
>
> **判划改只看一次：拿不准就认为是被划掉的。** 可疑处用 `pymupdf` 裁一张 `dpi=1000~1500` 的小图看一眼即可（本机 PIL 不可用，不要用 PIL 裁剪）；学生自己的删除线是横贯整个词的直线，字母间的连笔横向笔画、书法回锋都不是删除线。看完仍不能确定，就按划掉处理，继续往下做——**不要反复放大、来回比对，也不要为此停顿**。改完转写后必须回头复核 `errors[]` 是否仍然成立——被删掉的词可能正是某条错误判定的依据。

6. **错误分析详情**——前置实心黑星 ★ 的加粗标题；每条三段式：`【正确形式】`含修订标记的句子 → `【错误类型】`说明。同一句有多类错误时并列多条错误类型
7. **情节分析**——`{ 原文情节线 }` 居中标签 → 卡片`原文情节梳理` + 正文 → 卡片`续写情节推理` + `关键思考过程：…` + `第一段：（X+Y）：…` + `第二段：（X+Y）：…` + `小结：…` → 卡片`学生续写大纲`（每条提示句一行 + 大纲一行）→ 卡片`点评` + 点评正文 → `{ 衔接&过渡分析 }` 居中标签 + 分段的浅蓝药丸标签`第一段分析`／`第二段分析`，每段若干条检查项，每条格式 `{检查项}：{判定与说明} 优化建议：{具体英文替换句}`
8. **出彩表达**——绿色横条内心得式点评（如"这些词语像你给故事加的'小调料'…"）→ 编号条目，每条为 `{序号}.{学生原句}` + 若干 `【高级词汇】/【高级句型】/【高级短语】` 赏析
9. **个性化提升**——`● 细节描写提升` → 每条 `{序号}. {类别}`（动作描写／心理描写／语言描写／环境描写）+ `【学生原文】`/`【内容提升】`/`【点拨】` 三行；再 `● 结尾句提升` 同三行结构；再 `● 更多表达` 3 条同三行结构
10. **我的作文润色**——整合修订后的两段完整润色稿
11. **学生佳句**（**班级级**：同班共享、跨班不同）→ **场景词汇**（3 组 × 10 个短语，两列表格，场景名列 111 pt、词汇列 444 pt，单元格橙色描边）

> 板块 11 的归属实测结论：`学生佳句` 与 `场景词汇` 都随班级变化。同一班内每份报告共享**完全相同**的一组内容（包括佳句顺序）；换一个班，佳句的人名、句序以及场景词汇的措辞都会不同。因此聚合必须以班为单位，**绝不能跨班取材**。
>
> **佳句区允许出现学生本人的句子。** 佳句取的是本班所有学生中得分最高的前 N 句，学生自己写得好就会出现在自己的报告里——不要按人过滤掉本人那句（过滤会破坏"同班共享同一组"这条班级级定义）。另有实测现象：同一班内会有相当比例的报告该区块为空（全班尚未聚合完成或本批无候选），此时按样本报告的行为留空即可，不要补齐。

## 四、衔接&过渡分析的固定四类检查项

第一段分析：
- `你的第一句与提示句1的衔接`
- `你段内句子间的过渡`

第二段分析：
- `你的结尾句与提示句2的衔接`（注意：报告原文写作"你的结尾句"，指第一段结尾句）
- `你的第一句与提示句2的衔接`
- `你段内句子间的过渡`

判定用语固定为：`衔接不当` / `衔接生硬` / `衔接自然`；`存在多处逻辑跳跃` / `存在不符合场景的逻辑跳跃` / `过渡基本自然`。每条都必须给出可替换的具体英文句子作为 `优化建议`。

## 五、学生 JSON 数据契约

每名学生产出一个 JSON 文件，文件名 `{学号}_{姓名}.json`。

**本文件不含任何固定题目的情节**——`source_summary`／`p1`／`p2`／`outline`／`polish` 等所有内容都来自**当次 `assignment.json` 的原题 + 该生实际写的作文**。下例只标出字段形状与写法要求，`<…>` 处按当前这一题填；`score`／`word_count` 是数字字段（示例里占位写 0），实际填写该生真实得分与词数。

{

  "meta": { "assignment": "读后续写", "title_date": "<M>月<D>日", "date": "<YYYY/MM/DD>", "weekday": "星期<X>" },
  "score": 0,

`class_shared` 由 `aggregate.py` 统一回填，单篇批改阶段留空即可。`sentence_review.*_html` 与 `errors[].correct_form_html` 允许出现 `<del>` 标签，渲染器会保留；其余字段一律按纯文本转义。

### 修订标记的唯一写法

错误原文包 `<del>`，紧跟的订正文本包 `<ins>`：

```
学生写：  Slowly, the door opened and a gril came in.   （girl 拼成了 gril）
转写为：  Slowly, the door opened and a <del>gril</del> <ins>girl</ins> came in.
```

渲染出来就是：`gril` 红字带删除线，`girl` 灰底红字。**`<del>` 和 `<ins>` 必须成对出现**——只包 `<del>` 不包 `<ins>`，订正文本就丢了灰底，与样本报告不一致。

**不得用这对标签还原学生自己的涂改**——学生划掉的词按硬约束第 1 条直接不转写（见第三节板块 5 的转写规则）。

## 六、题目级配置 `assignment.json`

**每题一份，与题绑定，不可复用。** 换题时 `source_text`／`prompt1`／`prompt2`／`scene_vocab` 必须全部重写。

```json
{
  "assignment": "读后续写",
  "title_date": "<M>月<D>日",
  "date": "<YYYY/MM/DD>",
  "weekday": "星期<X>",
  "full_score": 25,
  "word_count_rule": "只统计学生自写内容，不计两句印好的提示句，划掉的词不重复计数",
  "source_text": "<当次原题前文，完整粘贴>",
  "prompt1": "<第一段已给出的首句，原文照抄>",
  "prompt2": "<第二段已给出的首句，原文照抄>",
  "scene_vocab": [
    { "scene": "<场景名1：本题前半段的主要动作场景>", "words": "<10 个短语>" },
    { "scene": "<场景名2：本题的内心/情感转折场景>", "words": "<10 个短语>" },
    { "scene": "<场景名3：本题结尾的落点场景>", "words": "<10 个短语>" }
  ],
  "scene_vocab_by_class": {
    "<N>班": [ { "scene": "<该班覆盖版场景名>", "words": "<10 个短语>" } ]
  }
}
```

**`scene` 怎么定**：读一遍当次原题，把情节切成三段（起—转—结），据此命名三个场景，例如"前半段的动作场景／中间的情感转折场景／结尾的落点场景"。**场景名必须来自当次题目的情节**，换题就换名。

**`words` 怎么写**：每组 10 个 `英文(中文)` 短语，英文与中文之间不加空格，英文短语与该题的场景、人物、动作匹配，用逗号分隔。这是给学生背的表达，要写成能在本题里直接套用的短语（动词短语优先）。`scene_vocab_by_class` 可选，用于给个别班覆盖（样本报告里各班措辞略有出入）。

**词数口径**：本 Skill 统一采用**「只算学生最终文本、不含印好的提示句、划掉的词不重复计数」**。实测两篇的对照：一篇自写 154 词、产品报 156；另一篇自写 75 词、产品报 80。差异来自对划掉词的计数处理，该口径可复现且与产品值相差在 5 词以内，**不要为了对齐产品而反向凑数**。
